## Service boundary

Website browsing reads `/api/v1/profile` without creating an anonymous identity. User-selected account actions reuse the retained HttpOnly-cookie/CSRF client and email/provider contracts. AUTH_REQUIRED and LINK_ACCOUNT_REQUIRED show sign-in and retire online polling. No passwords, OTPs, identity tokens or receipts are persisted by the website.

Local preview does not proxy account/game writes. An explicitly configured public-read proxy can call only the fixed leaderboard origin/path with bounded filters and no forwarded credentials. Current live V4 leaderboard requires authentication; this was observed with two sanitized, unauthenticated GETs. Anonymous production standings need an approved service route, and signed-in website/API deployment needs its real same-origin session/CSRF/callback configuration. The read seam does not bypass authentication.

The Store enables purchases only with server availability, a real billing bridge and actual localized prices. Delivery precedes provider finish. Sponsor placements are inactive until actual campaigns/network, disclosures and consent integration exist. Browser-local preferences are stored only after explicit consent, and can be cleared.
