Policy `enabled` check constraint refuses missing fields. Unapproved/synthetic placeholders **must not** be used in production.

A started or played invalid source is quarantined; resignation/timeout are **adjudicated**, never a fabricated board-value loss. Population is **UNKNOWN** unless private verified classification proves human-human.

### CLI notes

`node scripts/gameplay-capture.cjs <worker|reconcile|metrics|erase|suppress|export|journal|restore-journal|purge-exports|gate>` is **one shot**, intended for a separate external supervisor. No scheduling/provisioning occurs automatically. Exact environment validation lives in `packages/learning/connection.js`. `suppress` requires `CAPTURE_SUBJECT` and `CAPTURE_SUPPRESSION_REASON` from a trusted authenticated deletion/choice workflow. `restore-journal` additionally requires `CAPTURE_JOURNAL_FILE`, `CAPTURE_JOURNAL_SHA256`, `CAPTURE_REQUIRED_PRIVACY_EPOCH`, `CAPTURE_ISOLATED_RESTORE=1` and nonserving authorization. Export requires `CAPTURE_EXPORT_DIR`, `CAPTURE_KEY_FILE`, `CAPTURE_KEY_ID`, `CAPTURE_PSEUDONYM_KEY_FILE`, `CAPTURE_REQUIRED_PRIVACY_EPOCH`; per-move positions are disabled unless `CAPTURE_EXPORT_POSITIONS=1`. Keys and raw actor mappings never belong in a public receipt.

CI reproducer on owned disposable PG16: `node scripts/v5/migrate.js --dry-run --json`, `node --test --test-reporter=tap --test-concurrency=1 tests/gameplay-*.test.js`; CI uses Node24 and local isolated PostgreSQL16, and retains source manifest/tests. **Do not** use a staging or production database for those destructive test suites.
