## Rewarded Undo expansion (AM00-AM25)

It defines 26 actionable tasks, with exact interfaces, negative tests, owner and exit criteria. The nine checkpoints above are ordered alongside the 24 original release tasks. The new feature is **planned, not implemented**.

**Mode rule:** local Vs Bot gets the first optional ad-earned one-turn rewind. The guided tutorial, ranked, direct challenges and tournaments never acquire rewarded gameplay advantages. Online Casual is two-person Core-authoritative PvP and requires mutual consent, versioned move-history correction and a separate release decision. While planning/building, production ads stay OFF.

## Safe production sequencing and fail-closed rule

`owner/controller decisions + Apple/Google identity + real email + website/API/WSS + native and browser acceptance + DC00 15/15 + V5 alerting + pre-write P22 evidence`
→ `exact-build/maintenance-window acceptance`
→ `fresh V4 freeze/restore`
→ `final V4→PG import/reconciliation`
→ `prod-only role/image verification and independently governed pre-write permission`
→ `V4 writer fence (E4)`
→ `first V5 writer epoch/write (E5)`
→ `traffic switch, smoke, monitored forward recovery`
→ `retire V4 runtime, preserve Git+backups`.

**Stop condition:** if an applicable gate is missing, **do not perform E4 or E5**. A non-approved rewarded-undo beta must stay disabled. The owner's broad 2026-10-14 authorization is conditional and cannot turn missing provider, privacy or real-device proofs into PASS.
