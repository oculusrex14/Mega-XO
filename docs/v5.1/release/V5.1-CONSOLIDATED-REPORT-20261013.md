## TRACK A - serious AI research on both DGX Sparks

### What was diagnosed

The compact CNN's **value head was unlearnable**: trained on the eventual winner of weakly-played games,
it memorised the training set (MSE 0.010) and generalised to nothing (holdout 1.15, worse than predicting
zero 0.73). Data analysis showed the weak-game value target is near-unpredictable (within-group variance
0.662 of overall 0.731; material->outcome agreement 0.23 early). **The labels, not the architecture, were
the bottleneck** - exactly the owner's "stronger training targets" thesis.

### What fixed it

Replace the VALUE target with the **deep search's root score** and the POLICY target with **deep-search
visit counts** (`training/bot/search-labels.cjs`). Value MSE **1.08 -> 0.15-0.18**.

**Best candidate `big-w96b4`**: 714k params, 1.38 MB float / **381 KB INT8**, **0.29 ms/move** single-thread
CPU inference, point score **0.608** vs the tactical search and **0.050** vs the depth-12 Expert on 100
independent holdout families (CI [0.025, 0.077]). A genuinely useful lightweight client bot; **far below
the 0.70 promotion gate**.

### Honest conclusion

Within compact-CNN + strong-label training, the achievable strength is ~0.05 vs the depth-12 Expert. The
levers that "should" scale it - more capacity, more search, deeper labels, self-play - were each measured
and **did not**. Reaching 0.70 needs a fundamentally stronger method (large-scale AlphaZero-style RL with
a much bigger net and many GPU-hours) beyond the lightweight-client constraint this project targets.
