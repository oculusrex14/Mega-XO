# V5.2 tracked-tree prune — 2026-10-14

Scope: remove the historical screenshot/QA/raw-data bulk that the shipped app, the web build,
the CI lanes and the test suites do **not** need. Every path in V5.1 is preserved at
`freeze/V5.1-final-20261014` (= `077bfbc`), so all deletions below are reversible from V5.1.

## Commit attribution (read this first)

The 283 tree deletions were staged by this task with `git rm -r`, but a **concurrent commit from a
peer agent** — `61aedcf` "docs(v5.2): record the Android upload key and the signed release AAB" —
swept the shared index and carried those already-staged deletions into itself. The absorbed set is
byte-for-byte identical to the intended list (a `diff` of the two path sets is empty). History is
not rewritten (forbidden), so the tree deletions live in `61aedcf`; this document and the
`chore(v5.2): prune …` commit exist to make the record accurate and the intent explicit.
